# U2 qB Bot v2.1 自动部署说明

## Linux 一键安装

```bash
curl -fsSL https://raw.githubusercontent.com/qingzhh/public-resources/main/projects/u2-auto-follow-v2/scripts/install_u2_qb_bot.sh | bash
```

脚本会交互式要求输入：

- Web 端口
- Web 登录账号
- Web 登录密码
- qB 地址 / 用户名 / 密码
- U2 passkey
- CookieCloud 地址 / key / 密码

## 分享包里有哪些文件

- `u2_qb_bot.sh`
  机器人主程序。
- `u2_manager.py`
  状态库、手工加种、Web 控制台。
- `开发进度记录.md`
  记录近期修复、已验证结果、已知问题和后续升级方向。
- `u2_service.sh`
  手动启动、停止、看日志。
- `install_systemd.sh`
  在 VPS 上安装 `systemd` 开机自启服务。
- `deploy_vps_v2.1.ps1`
  Windows 端一键上传并部署到 VPS。
- `deploy.template.jsonc`
  给群友填写的部署模板，支持整行注释。
- `config.template.properties`
  传统配置模板，方便手动部署的人参考。

## 群友只需要改哪里

把 `deploy.template.jsonc` 复制一份，改名为 `deploy.jsonc`，然后只改下面这些值：

```jsonc
"ssh.host": "VPS IP"
"ssh.port": 22
"ssh.user": "root"
"ssh.password": "VPS 密码"

"u2.passkey": "你的 U2 passkey"
"u2.cookiecloud.url": "你的 CookieCloud 地址"
"u2.cookiecloud.key": "你的 CookieCloud key"
"u2.cookiecloud.password": "你的 CookieCloud 端到端密码"

"qb.url": "qB WebUI 地址"
"qb.user": "qB 用户名"
"qb.pass": "qB 密码"
```

一般不用改的值：

```jsonc
"install_dir": "/opt/u2-qb-bot"
"service_name": "u2-qb-bot"
"qb.category": "pt-u2"
"qb.up_limit_mb": 50
"qb.max_downloading": 0
"seed.readd_cooldown_minutes": 60
"shout.max_age_minutes": 120
"qb.min_free_space_gb": 0
"qb.session_refresh_seconds": 1500
"web.host": "0.0.0.0"
"web.port": 18081
"web.username": "admin"
"web.password": "你自己设一个强密码"
"web.session_hours": 12
"web.qb_refresh_seconds": 5
"magic.up_rates": "1.00,2.00,2.33"
"magic.use_thresholds": false

"dynamic.rule1.enabled": false
"dynamic.rule2.enabled": false
"log.archive_interval_minutes": 60

```

## 一键部署步骤

1. Windows 打开 PowerShell。
2. 进入分享包所在目录。
3. 复制模板：

```powershell
Copy-Item .\deploy.template.jsonc .\deploy.jsonc
```

4. 编辑 `deploy.jsonc`，把模板里的占位值换成自己的。
5. 运行部署：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy_vps_v2.1.ps1 -ConfigFile .\deploy.jsonc
```

## 部署完成后常用命令

```bash
cd /opt/u2-qb-bot
./u2_service.sh status
./u2_service.sh log
./u2_service.sh count
./u2_service.sh add 123456
./u2_service.sh web-status
./u2_service.sh web-log
systemctl status u2-qb-bot
systemctl status u2-qb-bot-web
systemctl restart u2-qb-bot
systemctl restart u2-qb-bot-web
```

## 重复上车与重新下载说明

- 现在不再用 `seen_ids.txt` 永久拦截同一个种子 ID。
- 改为记录“聊天事件”的状态到 `state.db`。
- 如果你后来把 qB 里的种子删掉，只要聊天区后面又出现新的魔法消息，就可以再次下载。
- 默认还有一个 `60` 分钟的重新加入冷却时间，可通过 `seed.readd_cooldown_minutes` 调整。

## 聊天消息过滤说明

- 默认只处理最近 `120` 分钟内的聊天魔法消息。
- 配置项是 `shout.max_age_minutes`。
- 设为 `0` 表示不按消息年龄过滤。

## 硬盘空间保护说明

- `qb.min_free_space_gb`
  小于这个剩余空间后，不再入种。
- 页面里还支持两档动态规则：
  - 剩余空间阈值
  - 种子大小范围
  - 上传 / 下载倍率门槛
- 用来在磁盘紧张时自动只收更合适的种子。

## CookieCloud 自动刷新说明

- 脚本每轮轮询前都会重新读取一次 CookieCloud。
- 如果浏览器重新登录了 U2，只要 CookieCloud 同步完成，下一轮就会自动用新 Cookie。
- 如果 CookieCloud 临时不可用，脚本会继续沿用上一轮还能用的 Cookie，不会立刻中断。

## qB 会话刷新说明

- 脚本会复用 qB 的 Cookie Jar，并在每次 qB API 请求时继续更新它。
- 默认会在 qB 会话达到 `1500` 秒后主动重新登录，减少会话过期后才被 `403` 触发恢复的概率。
- 如果你明确不想启用主动刷新，可以把 `qb.session_refresh_seconds` 设为 `0`。

## Web 控制台说明

- 默认端口是 `18081`。
- 登录账号来自 `web.username`。
- 登录密码来自 `web.password`。
- 登录后使用随机会话 ID Cookie，不会把密码原样写进 Cookie。
- 默认会话时长是 `12` 小时，可通过 `web.session_hours` 调整。
- 页面里可以查看最近事件、qB 状态、日志，支持手工输入 `种子ID` 加种。
- 设置页现在支持直接表单化修改常用配置，不需要优先编辑原始脚本。
- 支持导出事件 CSV、导出当前日志、手动归档日志。
- 如果部署目录里有 `deploy.jsonc`，页面也会一起显示和保存。

## 魔法匹配说明

- `magic.up_rates` 用于精确匹配常见倍率，例如 `1.00,2.00,2.33`。
- 如果启用 `magic.use_thresholds=true`，则会按下面两个阈值识别：
  - `magic.min_up_rate`
  - `magic.max_down_rate`
- 这样后续出现新倍率魔法时，只要满足阈值，也能自动识别。

## 分享时请注意

- 不要把你自己的 `config.properties` 发给别人。
- 不要把你自己的 `deploy.jsonc` 发给别人。
- 分享时只发模板和脚本，别发真实密码、真实 passkey、真实 CookieCloud key。
## v2.1 补充说明

- `seed.readd_cooldown_minutes` 默认建议改为 `1440`，避免 24 小时内重复下载同一种子。
- `qb.min_free_space_gb` 现在会同时检查“当前剩余空间”和“预计加种后剩余空间”。
- 新增 `./u2_service.sh check`，可在 VPS 上快速检查冷却、空间阈值、并发上限和 qB 连接。
- 新增 Telegram 服务：
  - `systemctl status u2-qb-bot-telegram`
  - `./u2_service.sh telegram-status`
  - `./u2_service.sh telegram-log`
- 新增配置项：
  - `telegram.bot_token`
  - `telegram.chat_id`
  - `telegram.poll_seconds`
