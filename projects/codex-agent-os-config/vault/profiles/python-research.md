# Profile: python-research

## 适用场景

- Python 数据处理、研究脚本、实验复现、分析和自动化任务。

## 工作原则

- 优先使用清晰、可复现、低副作用的脚本。
- 分离输入、处理、输出和验证。
- 对数据假设、随机性和环境依赖保持明确记录。

## 常用验证

- 最小样本运行
- 单元测试或断言
- 关键输出抽样检查
- 依赖和路径检查

## 禁止事项

- 不覆盖原始数据。
- 不记录大数据、长日志或完整实验输出到 Vault。
- 不把临时实验结论写成已验证事实。

## 交付格式

- 方法摘要
- 运行命令
- 验证结果
- 限制和下一步
