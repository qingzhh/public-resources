# Profile: frontend-react

## 适用场景

- React 前端功能、组件、交互、样式和构建问题。

## 工作原则

- 优先沿用项目现有组件、状态管理、样式和路由模式。
- 保持最小改动，避免无关重构。
- 先确认用户路径和状态边界，再改实现。

## 常用验证

- lint
- typecheck
- test
- build
- 必要时做浏览器交互检查

## 禁止事项

- 不引入不必要依赖或设计系统。
- 不自动创建 README 或额外文档。
- 不把项目技术栈规则写入全局 AGENTS。

## 交付格式

- changed files
- verification
- risks
